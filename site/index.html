Features

Everything you use every day.

The familiar GitHub Desktop flow — review, commit, branch, sync — rebuilt as a native Linux app.

Pick what you commit

Check the files to include, read a colored, line-numbered diff, write a summary and description, or amend the last commit.

Branches without friction

Searchable branch picker: create, switch, rename, delete, check out remote branches and merge into the current one.

One-click sync

A smart Fetch / Pull / Push / Publish button with ahead/behind counters and a quiet background fetch.

History that helps

Browse commits with refs and unpushed markers. Undo, revert, cherry-pick or start a branch from any commit.

GitHub sign-in

Reuse your gh login or paste a token — kept in your system keyring. Clone from your repo list and publish new ones.

Fits your desktop

Dark, light or system theme, English & French, keyboard shortcuts, and one click to your editor, terminal or file manager.

Screenshots

Looks right at home.

Follows the COSMIC theme on Pop!_OS and works on any Wayland or X11 desktop.

Configure NixOS ↓

NixOS module

The flake serves the prebuilt release binary, patched for NixOS — installing takes seconds.

# flake.nix
inputs.github-redesktop.url = "github:Kisakay/GithubReDesktop";

# in your nixosSystem modules
github-redesktop.nixosModules.default
{ programs.github-redesktop.enable = true; }

Home Manager / overlay

Prefer building it yourself? Use packages.<system>.github-redesktop-source.

# Home Manager
imports = [ github-redesktop.homeManagerModules.default ];
programs.github-redesktop.enable = true;

# or the overlay → pkgs.github-redesktop
nixpkgs.overlays = [ github-redesktop.overlays.default ];
