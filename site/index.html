GitHub Desktop, rebuilt natively for Linux

Review your changes, commit, switch branches and sync with GitHub. It is written in Rust with the COSMIC toolkit, so it opens instantly and follows your desktop theme.

Download for Linux View source on GitHub

Free and open source under the MIT license, for x86_64 and ARM64.

What you can do

The everyday GitHub Desktop workflow, without Electron.

  • Choose what you commitTick the files to include, read a line-numbered diff, then write a summary and description. Amend the last commit when you forgot something.
  • Work with branchesSearch, create, switch, rename and delete branches, check out remote ones and merge into the current branch.
  • Stay in syncOne button fetches, pulls, pushes or publishes depending on what your branch needs, with ahead and behind counts.
  • Read the historySee every commit with its files and diff. Undo, revert, cherry-pick, or start a branch from any commit.
  • Sign in to GitHubReuse your GitHub CLI login or paste a token, stored in your system keyring. Clone from your repository list and publish new repositories.
  • Keep your setupEvery action runs your own git, so hooks, SSH keys, signing and .gitconfig behave like in the terminal.
  • Open things where you workJump to your editor, terminal or file manager. Light, dark or system theme, in English or French.

How it looks

It uses the COSMIC theme on Pop!_OS and runs on any Wayland or X11 desktop.
